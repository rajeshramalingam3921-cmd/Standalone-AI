# திறன் AI — பயன்பாட்டு வழிகாட்டி

## அடிப்படைக் கருத்துகள்

| சொல்                  | பொருள்                                                                   |
| -------------------- | ----------------------------------------------------------------------- |
| **Project**          | உங்கள் ஒரு மென்பொருள். அதன் folder `WORKSPACE_ROOTS`-க்குள் இருக்க வேண்டும்.      |
| **Task**             | செய்ய வேண்டிய ஒரு வேலை (எ.கா. "Login page-இல் பிழை சரிசெய்").               |
| **திட்டம் (Plan)**     | AI files-ஐப் படித்து, என்ன செய்யப்போகிறது என்று சொல்வது. எதுவும் மாறாது.        |
| **மாற்றம் (Change)**   | Files-இல் செய்யப்போகும் மாற்றங்கள், diff ஆக. நீங்கள் அனுமதித்தால் மட்டுமே எழுதப்படும். |
| **சோதனைகள் (Checks)** | Settings-இல் நீங்கள் அமைத்த build / test / lint commands.                    |
| **செயல்பாட்டுப் பதிவு** | யார், எப்போது, என்ன செய்தார்கள் — மாற்ற முடியாத பதிவு.                         |

## முதல் முறை

1. **+ புதிய project** → பெயர், விளக்கம், tech stack.
2. Project → **Settings** → folder பாதை (எ.கா. `C:\Users\நீங்கள்\code\pos`), மற்றும் test command
   (எ.கா. `pnpm test`). "Folder அணுகக்கூடியது ✓" என்று வர வேண்டும்.
3. **சோதனைகள்** tab → **ஓட்டு** → test இப்போது என்ன நிலையில் உள்ளது என்று பாருங்கள்.

## AI-இடம் ஒரு வேலை கொடுப்பது

1. **Tasks** → தலைப்பு, தெளிவான விவரம் எழுதுங்கள் (எந்த file, என்ன நடக்க வேண்டும், எப்படிச் சோதிப்பது).
2. Task-ஐத் திறந்து **AI திட்டமிடட்டும்**.
3. திட்டத்தைப் படியுங்கள்:
   - சரி என்றால் **திட்டத்தை அனுமதி**.
   - இல்லையென்றால் **மாற்றம் கேள்** → என்ன மாற வேண்டும் என்று எழுதுங்கள்.
4. AI மாற்றங்களைத் தயாரிக்கும் → **"AI பரிந்துரைத்த மாற்றங்கள் தயார்"** → diff-ஐக் கவனமாகப் படியுங்கள்.
   - சரி என்றால் **அனுமதித்து எழுது** (இருமுறை தட்ட வேண்டும்).
   - தவறு என்றால் **நிராகரி**.
5. சோதனைகள் தானாக ஓடும். அறிக்கை:
   - ✅ **முடிந்தது** — எல்லாச் சோதனைகளும் வெற்றி.
   - ⚠️ **கவனம் தேவை** — சில சோதனைகள் தோல்வி, அல்லது சோதனைகள் அமைக்கப்படவில்லை.
     **AI திட்டமிடட்டும்** மீண்டும் தட்டினால், தோல்வி output-ஐ AI பார்த்து மீண்டும் முயற்சிக்கும்
     (ஒரு task-க்கு அதிகபட்சம் 3 முயற்சிகள்).
6. பிடிக்கவில்லையா? **மாற்றங்கள்** → அந்த மாற்றம் → **திரும்பப் பெறு (rollback)**.

## நீங்களே file-ஐத் திருத்துவது

**Files** → file → **திருத்து** → **மாற்றத்தைப் பரிந்துரை** → **மாற்றங்கள்**-இல் diff → அனுமதி.

## AI Chat

Project பற்றிக் கேள்விகள் கேட்க. Chat உங்கள் files-ஐப் பார்க்காது; தேவையான code-ஐ ஒட்டுங்கள்.

## பாதுகாப்பு — நினைவில் கொள்ள

- AI ஒருபோதும் நேரடியாக file எழுதாது, command ஓட்டாது. ஒவ்வொரு எழுத்துக்கும் உங்கள் அனுமதி தேவை.
- `.env`, keys, `.git`, `node_modules` ஆகியவற்றை AI-ஆல் பார்க்க முடியாது.
- "முடிந்தது" என்பது **உங்கள் tests வெற்றியடைந்தன** என்பது மட்டுமே. Tests இல்லாத பகுதிகளை நீங்களே சரிபாருங்கள்.
- AI-இன் சொந்தக் குறிப்பு "சரிபார்க்கப்படாதது" என்று குறிக்கப்பட்டிருக்கும் — அதை அப்படியே நம்ப வேண்டாம்.
- வாரம் ஒருமுறையாவது `pnpm backup`; backup-ஐ வேறு இடத்துக்கு நகலெடுங்கள்.
